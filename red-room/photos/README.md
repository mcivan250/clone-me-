# Photos

Drop the DJ press shots in this folder, then tell Claude they're here.

Use these exact filenames so the reveal posters pick them up without renaming:

```
alisha.jpg
tea.jpg
missterious2.jpg
hady.jpg
```

`.png` or `.webp` are fine too.

---

## Why this folder exists

Images pasted into a chat message arrive as something Claude can *look at* but not as
files it can read bytes from — so they can't be composited into a poster. Anything
committed here is a real file in the repo, which can be opened, duotoned and dropped
into the artwork.

So: commit the photos here, or attach them to a message as file uploads. Either works.
Pasting them into the chat does not.

---

## What each shot needs

| | |
|---|---|
| **Aperture** | 470 × 712 px inside the 1080 × 1350 poster. Supply at 1400 px wide or better. |
| **Crop** | 3:4 portrait, head and shoulders to mid-thigh. |
| **Eyeline** | Eyes on the **upper third**. The light is brightest at the top of the aperture and that's where the face has to sit. |
| **Missterious2** | They're a duo — frame them **two-up**, both faces in the upper half, not stacked. |
| **Background** | Plainer is better. A cut-out with a transparent background is ideal, since the doorway light replaces whatever is behind them. |
| **Resolution** | The bigger the better. These get cropped and graded. |

---

## What happens to them

1. **Duotone** to Red Room red and black — mids crushed, highlight held on the face,
   everything else dropped into shadow. Four shots taken in four different rooms will
   read as one set once they're graded.
2. **Silhouette variant** — a second version of each, filled solid black against the lit
   aperture. That's the teaser half of the reveal: silhouette first, full photo on the
   drop.
3. Both drop into the apertures in `../reveal.html`. The layouts don't move.
